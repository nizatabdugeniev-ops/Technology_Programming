# Учебный портал (student/teacher)

## Запуск

1. `cp .env.example .env`
2. Заполните пароли в `.env` или оставьте пустыми — при первом `node seed.js` они сгенерируются и выведутся в консоль.
3. `node seed.js`
4. `node server.js`
5. Откройте http://localhost:3000/login

**Примечание:** Пакеты `express`, `better-sqlite3`, `helmet` не удалось установить из-за ограничений окружения (EPERM на symlink, нативные модули). Использованы встроенные модули Node.js (`http`, `crypto`, `fs`). БД — JSON-файл `data.json`. CSP и security headers реализованы вручную.

## Как получить пароли

Запустите `node seed.js`. Если в `.env` пароли пустые, они будут сгенерированы и выведены один раз в консоль. После этого скопируйте их в `.env`.

```mermaid
  I --> A
```
